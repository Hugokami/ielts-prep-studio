## 🌟 Overview

**IELTS Prep Studio** is an all-in-one preparation ecosystem engineered to master the Cambridge IELTS Academic & General Training examinations (targeting Band 7.5 to 9.0). Operating seamlessly across web browsers and within Telegram, it combines authentic computer-delivered mock tests with criteria-referenced automated AI evaluation, spaced-repetition flashcards, and live academic tools.

📖 **For the exhaustive architectural, database, and API breakdown, see [APP_BREAKDOWN.md](APP_BREAKDOWN.md).**

---

## 🚀 Key Features

* **7 Core Study Hubs**:
  1. **Overview & Cirrus Daylight Hero**: Personalized greeting, live presence pulse, kinetic decrypted text with slow organic loop, and 5-pillar readiness diagnostics.
  2. **1,162 Academic Lexicon Items**: Spaced repetition flashcards with 1-3-7 Leitner system, bilingual Burmese glosses, phonetic IPA, and Oxford 3000/5000 alignment.
  3. **23 Cambridge Reading CBT Passages**: 231 examiner-grade questions with authentic split-pane passage viewer and real-time Band 9 scoring.
  4. **40 Writing Task 1 & 2 Models**: In-depth essay models, live draft autosave, and CEFR 90/10 analytical criteria-referenced evaluator.
  5. **Speaking Assistant & Forecast Simulator**: 30 seasonal forecast topics, 5 speaking frameworks (PREP, STAR, PEEP), and zero-mic live speech recognition.
  6. **Academic AI Tools Suite**: Collocations engine (`/collocate`), Band 8.5+ paraphraser (`/syn`), live dictionary (`/dict`), and exam countdown timers.
  7. **Cambridge AI Mentor Copilot**: Full-page borderless chat interface with animated liquid morphing orb and 4-tier zero-cost serverless failover.
* **Motion-Anything Design System (`/open-design`)**:
  * Kinetic `decrypted-text` with slow continuous loop and tab-visibility awareness.
  * 360° GPU-accelerated `star-border` glow on action buttons.
  * Dynamic `shiny-text` headers and multi-sentence `typewriter-multi` telemetry.
  * Tactile 3-bar slider settings toggle button.
* **Automated Payments & Administration**:
  * Dual-channel monetization: Local 55,000 MMK mobile wallets (KBZPay/WavePay) and worldwide 750 ★ Telegram Stars.
  * Accidental-approval prevention: Slips only forward to admin if user actively clicked "Buy VIP".
  * Automated spreadsheet delivery: Admin can type `/export` or `/customers` in Telegram to receive an Excel-compatible `.csv` file directly.
  * Real-time Google Sheets webhook sync for approved customer rows.

## 🛠️ Quick Start

### 1. Web / Desktop Usage
Open the live Progressive Web App directly:
**[https://hugokami.github.io/ielts-prep-studio/](https://hugokami.github.io/ielts-prep-studio/)**

To run locally:
```bash
git clone https://github.com/Hugokami/ielts-prep-studio.git
cd ielts-prep-studio
# Double-click index.html or serve locally
python -m http.server 8080
```

### 2. Telegram Mini App
Open Telegram and start the official bot:
**[@IELTSPrepStudioBot](https://t.me/IELTSPrepStudioBot)** or tap the bottom-left **`[ ▭ Open App ]`** button.
