# IELTS Prep Studio (Open Academic Edition)

> Comprehensive, offline-first, interactive IELTS Academic preparation suite featuring full practice tests, vocabulary constellation graphs, band score analytics, and mobile-optimized study tools.

## 🚀 Live Demo
Visit the live interactive application on GitHub Pages:
**[https://hugokami.github.io/ielts-prep-studio/](https://hugokami.github.io/ielts-prep-studio/)**

---

## 🌟 Key Features

- **Interactive Vocabulary Constellation**: Dynamic semantic network mapping Academic Word List (AWL) terms, collocations, and register.
- **5-Pillar Readiness Radar**: Real-time diagnostic chart tracking proficiency across Task Achievement, Coherence, Lexical Resource, Grammatical Accuracy, and Fluency.
- **Full Academic Practice Modules**:
  - **Academic Reading**: High-density passages with interactive question panels (T/F/NG, Headings, Summary Completion).
  - **Academic Writing (Tasks 1 & 2)**: Visual data interpretation prompts (bar charts, line graphs, process diagrams, maps) and essay drafting environments with band descriptor rubrics.
  - **Listening Simulator**: Audio track simulators with multi-part timed question forms.
  - **Speaking Assistant**: Part 1, 2, and 3 cue-card practice and response timings.
- **Mobile-First Responsive Design**:
  - Full touch and small-screen optimization down to 320px screen width.
  - No horizontal scrolling leakage or viewport displacement.
  - Responsive SVG charts, touch-friendly navigation toolbars, and scrollable data tables.
- **100% Offline-Capable**: Standalone single-page application with zero external runtime server requirements.

## 💻 Local Usage

Clone this repository and open `index.html` in any modern web browser:

```bash
git clone https://github.com/Hugokami/ielts-prep-studio.git
cd ielts-prep-studio
# Double-click index.html or open via browser
```
